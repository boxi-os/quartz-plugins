At build time

Every message begins with the path in the config, such as forms.contact.fields[2]: …. A problem stops the build and is printed in a batch as [forms] 2 problem(s) in the quartz-forms options:; a hint is a single line with [forms] in front. The same messages in German come from node .quartz/plugins/quartz-forms/dist/cli.js check --site . --lang de and from QuartzControl’s “Forms” tab.

In the browser

What the visitor reads is in the table of text keys (9.1). When the relay refuses, the browser turns the code into one of these sentences. Codes only the operator can fix (configuration, mail server, origin) it shows the visitor as “The message could not be sent. Please try again later.” and writes them with the code to the console:

quartz-forms: the relay refused form "contact" with recipient (the relay has no address for this form)
