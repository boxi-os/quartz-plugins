4.4 – The edge menu

17. Nov. 20264 Min. Lesezeit

rail (from 0.5.0) is a menu button where the layout puts the navigation, and a panel at the left
window edge. It has three states:

  1. closed: just the button, or with rail.rest: icons the strip from step 2 all the time;
  2. strip: a narrow column with the icons of the first level. Where no icon is set (navIcon,
    nodeIcons) or the SVG file cannot be used (7.1), the
    first letter of the title stands in;
  3. open: the strip widens into the whole menu with titles. Folders expand as in the accordion,
    the path to the current page is open.

The edge menu belongs in the header or another area that does not scroll. The panel starts below the
site’s top bar (the nearest ancestor with position: sticky or fixed), at the top edge without
one; --quartz-nav-rail-top sets the position yourself.

Opening and closing

OptionValuesDefaultEffect
rail.sideleft, rightleftwindow edge of the panel
rail.resthidden, iconshiddenat rest just the button, or the strip
rail.expandhover, strip, clickhoverhover: the pointer on the button shows the strip, on the strip the whole menu; strip: only the strip reacts to hover; click: by click only
rail.pintrue, falsetruea pin button in the open menu
rail.startPinnedtrue, falsefalsethe menu starts pinned (from 0.5.1, needs rail.pin)
rail.onNavigateclose, keepclosea link in the open menu closes it, or the next page shows it open until the pointer leaves

Opened by hover, the menu closes as soon as the pointer leaves it, even after a click inside. Opened
by click or keyboard, it stays until a click beside it, Escape, the button or a page change. Touch
screens always open by click.

Pinned, the menu stays open, across page changes too; the browser remembers it per navigation
(localStorage, by id). The pin button or the menu button unpins it; where hover opens the menu
(rail.expand: hover or strip), it then closes as soon as the pointer leaves it. With
rail.startPinned a visitor sees the menu pinned on the first visit already; if they unpin it, the
browser remembers that too, until they pin it again. Pinning holds on wide screens only: on a phone a pinned menu opens and
closes like any other. So that a reload does not show the page without the menu first and then jump,
a small script in <head> shows it before the first paint.

Two edge menus need an id

Two entries with the same options get the same key and share what the browser remembers. An id
of their own keeps them apart.

Over the page or beside it

OptionValuesDefaultEffect
rail.contentoverlay, pushoverlaythe menu lies over the page or pushes it aside by its width
rail.hoverContentsame, overlay, pushsamethe same for everything hover shows; same follows rail.content
rail.pinContentsame, overlay, pushsamethe same for a pinned menu

With content: overlay and pinContent: push the menu lies over the page until it is pinned, then
it sits beside it. With hoverContent: overlay the page stays still when the pointer only passes by.

While pushing, the plugin pads <body>, animated, and writes the width to
--quartz-nav-rail-offset-left (or -right) on <html>. Where pushing would leave the page less
room than the mobile breakpoint, the menu lies over it instead.

A header across the full width

A header reaching both window edges moves along when the page is pushed, although the panel starts
below it. This keeps it in place:

In QuartzHub the switch “Full window width” on a frame’s header area does it; the base template
already connects it with the edge menu.

On a phone

Below the mobile breakpoint there is no strip: the button opens the whole menu over the dimmed page,
also with rest: icons. mobile: select and hidden work as with the other variants; the edge menu
ignores accordion and offcanvas with a message (9.2),
as it slides in by itself.

Appearance

Widths and heights have variables of their own (7.2):
--quartz-nav-rail-width (strip), --quartz-nav-rail-open-width (open menu),
--quartz-nav-rail-row-height, --quartz-nav-rail-icon-size and --quartz-nav-rail-z. The pin
icons are iconNames.pin and iconNames.unpin (7.1).
